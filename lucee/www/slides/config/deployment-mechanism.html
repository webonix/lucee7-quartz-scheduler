Using the Deployment Mechanism

Lucee provides a "deploy" folder where you can place configuration files that Lucee will automatically pick up and install.

To update your Quartz Scheduler configuration:

  1. Create a file named config.quartz with your configuration
  2. Place it in the Lucee deploy directory {lucee-server}/lucee-server/deploy/
  3. Lucee will detect and process it within a minute
  4. This mechanism updates the existing configuration rather than replacing it completely.

bash
cd /opt/lucee/server/lucee-server/deploy/  
vi config.quartz
ls -l 
        
{
    "jobs": [
        {
            "label": "put a load on the cpu every 23 seconds",
            "url": "/cron/systemoutput.cfm?test=23",
            "interval": 19,
            "pause": true,
            "schedule": "interval"
        },
        {
            "label": "put a load on the cpu every 5 seconds",
            "component": "quartz.cpuLoad",
            "interval": 5,
            "pause": false,
            "duration": 50,
            "schedule": "interval",
            "load": 80
        }
    ]
}
